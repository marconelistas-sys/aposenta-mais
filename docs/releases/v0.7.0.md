# Aposenta+ v0.7.0

27 de novembro de 2026.

- Gráficos de fluxo e gastos do panorama mais fáceis de ler. Ponte do saldo, desvio por categoria e cota anual usam a mesma linha: valor com sinal ao lado da barra e situação escrita, sem depender só da cor. A cota anual mostra a trilha inteira como 100% e a linha do ritmo esperado.
- Simulações comparam a hipótese em edição com o plano completo: orçamento recorrente, dívidas, liquidez e consumo do patrimônio depois da aposentadoria, no mesmo calendário e com saldos negativos visíveis.
- Panorama com os capítulos "Sua carteira de verdade" e "Quantas vezes o custo mensal" (1%, Liberdade e Legado).
- Ajustes na compra de bens e no planejamento anual.

Os dados salvos permanecem compatíveis. Não há migração de banco. Os gráficos novos mudam só a apresentação; os números do panorama são os mesmos.

Para executar, use Node.js 24 ou superior e `npm run dev`. Para validar, use `npm run validate`, `npm run test:report-browser` e `npm run test:simulation-browser`.
