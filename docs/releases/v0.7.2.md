# Aposenta+ v0.7.2

27 de novembro de 2026.

- Ponte do saldo no Panorama (capítulo Fluxo de caixa e poupança) mais fácil de ler. O título diz a diferença ("Saldo realizado de X: Y abaixo dos Z planejados"). Cada desvio é uma barra a partir do zero, na mesma escala: para a direita aumentou o saldo, para a esquerda reduziu. A última linha soma os desvios e dá a diferença entre realizado e planejado.
- A ponte projetada do patrimônio segue o mesmo formato, com a variação no ano na última linha.

Os dados salvos permanecem compatíveis. Não há migração de banco. Os cálculos não mudaram; o PDF do Panorama continua com 14 páginas.

Para executar, use Node.js 24 ou superior e `./run-app.sh` (ou `./run-app.sh --rede` para o celular). Para validar, use `npm run validate` e `npm run test:report-browser`.
