# Aposenta+ v0.7.1

27 de novembro de 2026.

- Uso no celular pela mesma rede Wi-Fi: `./run-app.sh --rede` mostra o endereço do Mac na rede. O app pode ser adicionado à tela inicial do iPhone e do Android, com ícone próprio e tela cheia. A conexão é HTTP, sem criptografia; use só em uma rede de confiança. Sem a opção, o servidor continua acessível apenas pelo próprio Mac.
- Barra de Orçamento → Categorias mais fácil de ler: legenda "Como ler a barra", situação escrita em cada linha e no total ("x% acima do planejado", "abaixo", "igual"), parte acima do planejado com hachura e traço do planejado sempre visível. No celular, planejado e realizado não se sobrepõem mais.

Os dados salvos permanecem compatíveis. Não há migração de banco. Os cálculos do orçamento não mudaram.

Para executar, use Node.js 24 ou superior e `./run-app.sh` (ou `./run-app.sh --rede` para o celular). Para validar, use `npm run validate` e `npm run test:budget-categories-browser`.
