# Sprint 0

## Objetivo

Estabelecer uma base verificável para o MVP de planejamento da aposentadoria.

## Entregas

- Visão, público e proposta de valor.
- Escopo e backlog inicial.
- Arquitetura e decisões técnicas.
- Convenções e casos financeiros de referência.
- Contrato inicial para uma API futura.
- Testes automatizados.
- Validação contínua.
- Regras de segurança e uso de inteligência artificial.

## Decisões aceitas

- O MVP atende uma pessoa por plano.
- A projeção trabalha em reais de hoje.
- O horizonte padrão termina aos 95 anos.
- O usuário informa a estimativa gerada pelo Meu INSS.
- O MVP não recomenda produtos financeiros específicos.
- Open Finance será avaliado após a validação comercial.
- O piloto terá entre 30 e 50 participantes.

## Critérios de saída

- Motor financeiro separado da interface.
- Convenções de taxas documentadas.
- Testes e build executados com sucesso.
- Contrato inicial de projeção documentado.
- Nenhum dado financeiro real incluído no repositório.
- Backlog da próxima etapa registrado.
