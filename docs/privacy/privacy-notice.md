# Aviso de privacidade do protótipo

## Resumo

O Aposenta+ atual é um protótipo sem cadastro, login, servidor de aplicação, API ou banco de dados. Os dados informados ficam no armazenamento local do navegador e não são enviados pela aplicação.

## O que é armazenado e por quê

- Idade, patrimônio, aporte, renda desejada e premissas para calcular projeções.
- Cenários para permitir comparações.
- Preferências de visibilidade, lembrete e gráfico para manter a experiência escolhida.

## Onde e por quanto tempo

As informações ficam no perfil do navegador usado. Permanecem até o usuário escolher “Apagar meus dados”, limpar os dados do site ou remover o perfil do navegador. Não há sincronização entre dispositivos.

## Controles do usuário

O perfil permite exportar uma cópia JSON e apagar os dados locais. A exclusão local é irreversível. Restaurar a demonstração é uma ação separada.

## Limites

Ocultar valores é uma escolha visual, não criptografia. Pessoas com acesso ao dispositivo, extensões e scripts executados na mesma origem podem alcançar o armazenamento local. Arquivos exportados ficam sob a guarda do usuário.

## Pendências antes de uma versão com servidor

O controlador, o contato de privacidade, as bases legais, os prazos de retenção e o processo de atendimento aos direitos previstos na LGPD ainda devem ser definidos. Esta documentação não declara conformidade integral com a lei.
