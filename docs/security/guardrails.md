# Guardrails de segurança e produto

- Não registrar CPF, extratos, tokens ou documentos em logs.
- Usar somente dados fictícios em desenvolvimento e testes.
- Manter consentimentos separados por finalidade quando houver persistência.
- Permitir acesso, correção, exportação e exclusão dos dados persistidos.
- Não indicar ação, fundo, título ou emissor específico no MVP.
- Não apresentar projeções como garantia.
- Validar números de explicações geradas contra a saída do motor.
- Revisar mudanças nas fórmulas com testes financeiros de referência.
